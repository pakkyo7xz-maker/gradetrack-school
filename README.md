# GradeTrack – ระบบรายงานและติดตามนักเรียนติด 0 ร มส

Web App (React + TypeScript + Vite + Tailwind) สำหรับโรงเรียนมัธยม ใช้นำเข้า Excel ผลการเรียน และติดตามการแก้ 0 / ร / มส
ข้อมูลทั้งหมดเก็บใน **localStorage ของเบราว์เซอร์** ไม่มีฐานข้อมูลออนไลน์ ไม่ส่งข้อมูลออกนอกเครื่อง

## เริ่มใช้งาน

```bash
npm install
npm run dev        # เปิด http://localhost:5173
```

```bash
npm run build      # ตรวจ TypeScript + build ไปที่ dist/
npm run preview    # เปิดไฟล์ build ที่ http://localhost:4173
```

### เปิดเป็นเว็บแอป (ไม่ต้องติดตั้ง)

```bash
npm run build:web      # สร้าง dist-artifact/gradetrack.html (HTML ไฟล์เดียว รวม CSS/JS)
```

ไฟล์นี้เผยแพร่เป็นหน้าเว็บบน claude.ai (Artifact) ได้ การส่งออก Excel/ไฟล์สำรองบนเว็บจะผ่านหน้าต่างยืนยันการบันทึกของแพลตฟอร์ม
ข้อมูลนักเรียนยังเก็บใน localStorage ของเบราว์เซอร์ผู้เปิดเท่านั้น (แต่ละคน/แต่ละเครื่องแยกกัน) — ควรส่งออกไฟล์สำรองเป็นประจำ

### เผยแพร่เป็นเว็บของตัวเอง (GitHub Pages)

`.github/workflows/deploy-pages.yml` สร้างและเผยแพร่เว็บให้อัตโนมัติทุกครั้งที่ push — ต้องตั้งค่าครั้งเดียว:
1. Settings → General → Danger Zone → Change visibility → **Public** (GitHub Pages ของ repo ส่วนตัวต้องใช้แพ็กเกจเสียเงิน)
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**
3. Actions → Deploy web app → Run workflow

เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/gradetrack-school/` — หรือใช้ `npm run build:web -- site/index.html --standalone`
แล้วนำไฟล์ `index.html` ไปวางบนเว็บโฮสต์ใดก็ได้ / เปิดตรงจากเครื่องได้เลย

ครั้งแรกระบบจะแสดง **ข้อมูลตัวอย่าง (สมมติ) 18 รายการ** — ไปที่เมนู "นำเข้า Excel" เพื่อใช้ข้อมูลจริง

## หน้าต่างๆ

| เมนู | ใช้ทำอะไร |
| --- | --- |
| สถิติ/ภาพรวม | 4 แท็บ: ภาพรวมโรงเรียน / รายระดับชั้น ม.1–ม.6 / รายห้อง (เลือกระดับ → ห้อง) / ครูผู้สอน — จำนวนคนไม่ซ้ำ, ร้อยละ 2 ตำแหน่ง, จำนวนรายการแยก, กราฟแท่ง 0 ร มส, คลิกตัวเลขเพื่อดูรายชื่อ, ส่งออก Excel แยกแท็บหรือรวมทุกแท็บ |
| จำนวนนักเรียน | จำนวนนักเรียนทั้งหมดต่อห้อง (ตัวหารของร้อยละ) — กรอกเอง หรือนำเข้า Excel/CSV แบบตารางจำนวน หรือรายชื่อนักเรียนทั้งหมด |
| ห้องเรียน | เลือกระดับชั้น → ห้อง (สร้างจากข้อมูลจริง) ดูรายชื่อ วิชาที่ติด ครูที่เกี่ยวข้อง ครูประจำชั้น สถานะ |
| ติดตาม/รายงาน | ตารางหลัก แก้สถานะ / วันกำหนด / หมายเหตุได้ทันที, กรองห้อง ครู ประเภท สถานะ, ค้นหาชื่อ, ส่งออก Excel |
| ครูผู้สอน | รายชื่อครู วิชา จำนวนนักเรียนที่ติด ยังไม่แก้/แก้แล้ว — คลิกชื่อเพื่อกรองรายการ |
| นำเข้า Excel | .xlsx/.xls/.csv: เลือกไฟล์ → Sheet → แถวหัวตาราง → ดูตัวอย่าง → จับคู่คอลัมน์ → ตรวจรายการซ้ำ/ไม่ครบ/รหัสขัดแย้ง → ยืนยัน |
| สำรองข้อมูล | ส่งออก/นำเข้าไฟล์ .json (รวมสถานะการติดตาม), ล้างสถานะที่ไม่มีรายการคู่, รีเซ็ต |

## โครงสร้างโค้ด

```
src/lib/types.ts          Data Model (GradeRecord, Tracking, สถานะ 4 ระดับ)
src/lib/importMapping.ts  ชื่อหัวคอลัมน์ที่รองรับ (aliases) + แปลงแถว Excel → GradeRecord
src/lib/normalize.ts      แปลงผลการเรียน / ชั้นห้อง / วันที่ / เลขไทย + คีย์จับคู่สถานะ
src/lib/stats.ts          กฎการคำนวณสถิติ (คนไม่ซ้ำ / ร้อยละ / รายการ)
src/lib/statsExport.ts    ส่งออกรายงานสถิติ Excel
src/lib/validation.ts     ตรวจความถูกต้องก่อนนำเข้า
src/lib/storage.ts        อ่าน-เขียน localStorage อย่างปลอดภัย
src/lib/excel.ts          อ่าน Excel, ส่งออกรายงาน, ไฟล์สำรอง
src/lib/sampleData.ts     ข้อมูลจำลอง (ชื่อสมมติทั้งหมด)
src/pages/*               หน้าจอแต่ละเมนู
```

**สถานะการติดตามไม่หายเมื่อนำเข้าไฟล์ใหม่:** สถานะเก็บแยกจากรายการ ผูกด้วยคีย์
`รหัสนักเรียน (หรือ ชื่อ+ห้อง) + รหัสวิชา (หรือ ชื่อวิชา)` เมื่อนำเข้าไฟล์ใหม่ที่มีนักเรียน+วิชาเดิม สถานะจะกลับมาอัตโนมัติ

## กฎการคำนวณสถิติ

- นับ **คน** ไม่ซ้ำด้วยรหัสนักเรียน (ไม่มีรหัส → ชื่อ+ห้อง) นักเรียนที่ติดหลายวิชานับ 1 คน; **รายการ** = จำนวนรายวิชาที่ติด แสดงแยกเสมอ
- ร้อยละนักเรียนที่ติด = คนไม่ซ้ำที่ติด / นักเรียนทั้งหมดในกลุ่ม × 100
- ร้อยละ 0 / ร / มส = คนไม่ซ้ำที่ติดประเภทนั้น / นักเรียนทั้งหมดในกลุ่ม × 100 (รวมกันเกินร้อยละรวมได้)
- นักเรียนทั้งหมดของระดับ/โรงเรียน = ผลรวมของทุกห้อง **เฉพาะเมื่อมีครบทุกห้อง** ถ้าขาดห้องใด หรือจำนวนที่ติดมากกว่าจำนวนทั้งหมด → แสดง "—" ไม่คำนวณแทน
- ล้างจำนวนของห้องในหน้า "จำนวนนักเรียน" = ห้องยังอยู่แต่ไม่ทราบจำนวน (ตัวหารไม่ลดลงเงียบๆ) ใช้ปุ่ม "ลบห้อง" เมื่อห้องนั้นไม่มีอยู่จริง

## ข้อมูลจาก PDF

แปลง PDF เป็น Excel หรือ CSV ก่อน (เช่น ด้วย Excel "Get Data from PDF" หรือเครื่องมือแปลง) แล้วนำเข้าผ่านหน้า "นำเข้า Excel" หรือ "จำนวนนักเรียน"
ระบบจะข้ามแถวสรุป "รวม" อ่านเลขไทย และแสดงผลตรวจสอบ (รหัสซ้ำชื่อต่าง, นักเรียนอยู่หลายห้อง, ห้องรูปแบบผิด, จำนวนที่ติดเกินจำนวนทั้งหมด) ก่อนยืนยัน

## รูปแบบไฟล์ที่ทดสอบกับไฟล์จริงแล้ว

ไฟล์ติดตามนักเรียนภาคเรียน 1/2569 (แปลงจาก PDF) มี 2 Sheet — ระบบเลือก Sheet **"รายวิชาและครูผู้สอน"** ให้อัตโนมัติ
(1 แถวต่อ 1 วิชา: ห้อง | เลขที่ | รหัสนักเรียน | ชื่อ–นามสกุล | รหัสวิชา | รายวิชา | ผลการเรียน | ครูผู้สอน | หน้า PDF)
หัวตารางอยู่แถวที่ 5 (ระบบหาให้เอง) และนำเข้าได้ครบโดยไม่ต้องปรับ mapping
ไฟล์นี้ไม่มีจำนวนนักเรียนทั้งหมดต่อห้อง → ต้องนำเข้าที่เมนู "จำนวนนักเรียน" ก่อนจึงจะเห็นร้อยละ
ห้องที่ไม่มีนักเรียนติดเลยจะไม่อยู่ในไฟล์นี้ ต้องเพิ่มห้องเหล่านั้นในหน้า "จำนวนนักเรียน" ด้วย ไม่งั้นตัวหารของระดับชั้นจะไม่ครบ

## เมื่อได้รับไฟล์ Excel จริง ต้องปรับอะไร

1. **ลองนำเข้าผ่านหน้า "นำเข้า Excel" ก่อน** — ถ้าระบบจับคู่คอลัมน์ไม่ถูก ปรับ dropdown ได้เลย ระบบจำ mapping ล่าสุดไว้ให้
2. ถ้าหัวคอลัมน์ของโรงเรียนไม่อยู่ในรายการ ให้เพิ่มคำใน `aliases` ของ `FIELDS` ใน `src/lib/importMapping.ts`
3. ถ้าผลการเรียนเขียนต่างไป (เช่น `มผ`, `ร.`) ให้ปรับ `normalizeResult` ใน `src/lib/normalize.ts`
4. ถ้าชั้น/ห้องเป็นรูปแบบอื่น (เช่น `M.1/1`, `101`) ให้ปรับ `normalizeClassroom`
5. ถ้าไฟล์เป็น **แบบตารางกว้าง** (1 แถว = 1 นักเรียน, วิชาเป็นคอลัมน์) ต้องเพิ่มขั้นตอนแปลงเป็น 1 แถวต่อ 1 วิชาใน `parseRows`
6. ถ้ารหัสนักเรียนไม่มีในไฟล์ ระบบจะใช้ ชื่อ+ห้อง เป็นคีย์ — ถ้าชื่อสะกดต่างกันระหว่างไฟล์ สถานะจะไม่ผูกคืน
7. นำเข้าจำนวนนักเรียนทั้งหมดต่อห้องจากทะเบียนจริงในหน้า "จำนวนนักเรียน" (ข้อมูลตัวอย่างใช้ค่าสมมติ) ถ้าหัวคอลัมน์ไม่ตรง เพิ่มใน `ENROLL_FIELDS`
8. ห้าม commit ไฟล์ Excel/ไฟล์สำรองที่มีข้อมูลจริงเข้า repo (`.gitignore` กันไว้แล้ว)

## หมายเหตุด้านความปลอดภัย

ใช้ `xlsx` 0.18.5 จาก npm ซึ่งมีช่องโหว่ที่รู้จัก (prototype pollution / ReDoS) เมื่ออ่านไฟล์ที่ไม่น่าเชื่อถือ
ควรเปิดเฉพาะไฟล์จากระบบของโรงเรียน หากเป็นไปได้ให้อัปเกรดเป็นเวอร์ชันจาก SheetJS CDN:

```bash
npm i https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz
```
